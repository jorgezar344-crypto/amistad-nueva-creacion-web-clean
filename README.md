# 🏛️ Amistad Nueva Creación Internacional — Web Oficial & Experiencia 3D

Plataforma digital oficial de **Amistad Nueva Creación Internacional** (Querétaro, México) y experiencia interactiva tridimensional **Los 9 Pasos: Un camino para crecer en Cristo**.

---

## 🚀 Tecnologías Principales

- **Framework:** [Next.js 14 (App Router)](https://nextjs.org/)
- **Lenguaje:** [TypeScript](https://www.typescriptlang.org/)
- **Estilizado:** [Tailwind CSS](https://tailwindcss.com/)
- **Gráficos 3D:** [Three.js](https://threejs.org/)
- **Audio Contemplativo:** Web Audio API (síntesis en tiempo real)
- **Despliegue:** [EasyPanel](https://easypanel.io/) / Node.js Standalone

---

## 🛠️ Comandos de Desarrollo y Producción

```bash
# Instalar dependencias
npm install

# Iniciar servidor de desarrollo
npm run dev

# Compilar para producción
npm run build

# Iniciar servidor de producción
npm run start
```

---

## 📖 Arquitectura de Rutas

- `/` : Home Institucional de la Iglesia (Hero con auditorio real, Primera Visita, Horarios, Prédica en video, Ubicación con acceso real en Camino a Lourdes).
- `/9-pasos` : Experiencia inmersiva 3D con recorrido spline continuo a través de los 9 pasos canónicos de crecimiento espiritual.
